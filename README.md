# Fire Emblem: Radiant Dawn — Bản Việt hóa

Bản Việt hóa của người hâm mộ, thực hiện bởi **Unoken**. Trang giới thiệu và tiến độ: https://unoken.github.io/FE10-VietHoa/

Dự án đang thực hiện; bản vá sẽ phát hành một lần khi đã dịch xong toàn bộ game. Repo này chỉ chứa trang web, không chứa game hay dữ liệu đĩa gốc.
